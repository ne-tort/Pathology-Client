# Pathology Client

Multi-platform VPN client for Android, Windows and Linux, built on the
sing-box core.

This repository is the **public downloads mirror** вЂ” it intentionally contains
no source code, only releases published by CI.

## Download

Get the latest build from [**Releases**](https://github.com/ne-tort/Pathology-Client/releases):

| OS | Artifact |
| --- | --- |
| Android | `Pathology-Android-universal.apk` (or per-ABI: arm64 / arm7 / x86_64) |
| Windows | `Pathology-Windows-Setup-x64.exe`, portable `zip` / `7z` |
| Linux | `Pathology-Linux-x64-AppImage.AppImage` (+ `tar.gz`), `Pathology-Debian-x64.deb` |

The app updates itself automatically from this repository.
